# MrEsfahan Brand System

## Core palette
- Velvet Black — primary foundation
- Warm Gold / Yellow — primary identity accent
- Blue — secondary functional accent

## UI direction
Premium modern glassmorphism, strong contrast, restrained glow, semantic layering, accessibility-first.

## Rule
The exact production hex values must be taken from the approved MrEsfahan master palette before final UI implementation. Do not invent replacement brand values.
