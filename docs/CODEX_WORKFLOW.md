# Codex Workflow

Codex is the implementation agent, not the final authority.

1. Read AGENTS.md and project registry.
2. Inspect repository state.
3. Create a scoped feature branch.
4. Implement the smallest verifiable change.
5. Run build/tests/lint/security checks.
6. Report exact evidence.
7. Open a Pull Request.
8. Human/GPT Super Master review.
9. Merge only after approval.

Never claim build/runtime success without evidence.
