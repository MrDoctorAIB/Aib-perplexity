# AIB NEXUS — Master Whitepaper — Part I

## Purpose
AIB NEXUS is the online intelligence and orchestration layer connecting AI models to the AIC offline executor.

## System chain
AI Model → AIB NEXUS → AIC → Android
Android → AIC → AIB NEXUS → AI Model

## Authority model
1. User — final authority
2. GPT Super Master — decision/orchestration authority
3. Specialized agents — bounded expert roles
4. AIB NEXUS — coordination, contracts, task state, verification
5. AIC — execution
6. Android — execution environment

## Pilot
Pilot is a formal lifecycle phase used by AIB and AIC.

## Verification rule
No feature is considered complete without source, build, runtime, and test evidence.
