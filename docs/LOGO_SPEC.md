# AIB NEXUS Logo Specification

## Concept
A premium intelligence-bridge identity derived from the MrEsfahan visual language.

## Requirements
- recognizable at small sizes
- black foundation
- warm-gold primary mark
- blue secondary signal
- suitable for app icon, GitHub avatar, splash, documentation, and favicon
- vector-first source
- transparent and dark-background variants

## Constraint
Do not replace the approved MrEsfahan bird/logo geometry with an unrelated generic AI icon.
