# App Frame & UI Foundation

## Direction
Premium, modern, accessibility-first, MrEsfahan brand.

## Layers
1. Velvet-black base
2. Glass surface
3. Warm-gold identity/action accent
4. Blue information/status accent
5. High-contrast semantic text

## Core frame
- rounded premium shell
- restrained glass effect
- strong focus state
- semantic status bar
- voice/microphone entry point
- accessibility-safe touch targets
- no decorative element may obscure functional controls

Final dimensions, typography, icons, and exact color tokens require the approved design artifact before implementation.
